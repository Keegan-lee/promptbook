# Bolt News images and maps

Owner decisions 2026-10-28. Site schema and renderer own the fields; this file is the writer/reviewer contract.

## Required on every new post before Draft Ready

1. **Cover** — Sanity `cover` image, master **3:2** with hotspot. Alt required (one plain sentence). Drives article hero, index card, Studio preview. OG/Twitter are **generated by the site** from cover + title (do not upload a separate social file).
2. **At least one in-body `figureImage`** (opening and/or dossier). Caps: opening **max 1**; dossier news brief **1–2**, explainer **2–4**; hard ceiling **5** in-body images total.
3. Caption optional. Structured credit fields: `creator`, `sourceTitle`, `sourceUrl`, `license`, `needsAttribution`, `sourceKind` (`stock` | `ai` | `upload`). Show on-page credit only when `needsAttribution` is true.

Same rules for news briefs and explainers.

## Stock then AI (no Vercel AI Gateway; Pexels paused)

Order:

1. **Wikimedia Commons** (no key). Prefer public-domain / CC0 when possible. Set `needsAttribution` from the license.
2. **Unsplash** — env `UNSPLASH_ACCESS_KEY` or `UNSPLASH_ACCESS_TOKEN` (Doppler `bolt-news`). Hit the download endpoint, then upload bytes to Sanity. Unsplash does not require attribution (`needsAttribution: false`); still store creator + source URL.
3. **Sanity AI** (`generate_image` / Agent Actions) only when stock misses **and** the subject is a place, ruin, or object. Prompt must name the real place and distinctive features; photorealistic and faithful — never a generic “ruins of X” motif. No on-asset AI disclosure. Each Agent Action costs Sanity AI credits — one cover attempt, reuse; do not regenerate casually. Prefer reference wording from a weak stock hit if you saw one.

Forbidden: other publications' covers, episode artwork, watermarks, Vercel AI Gateway spend, Pexels while paused.

Helpers in the site repo (Doppler-wrapped): `src/lib/media/resolveStock.ts`, `unsplash.ts`, `wikimedia.ts`, `sanityUpload.ts`.

## Location map (`locationMap`)

Named when a real site is central — especially Ancient Civilizations; optional on other rails.

Fields: `placeName`, `lat`, `lng`, optional `zoom` (default 12), `caption`, `sourceTitle`, `sourceUrl` (coordinate source). Site renders click-to-load Leaflet + OSM, a static map for crawlers, and Place / GeoCoordinates JSON-LD.

## Writer Step 7 override

A missing cover or zero in-body images **blocks** Draft Ready (do not leave empty with only `needs cover`). Agent may set images without a human glance when Approval Mode is Agent.

## Credit-sparing Sanity AI

- Stock first every time.
- AI only for places/ruins/objects after stock miss.
- One successful cover; in-body AI only if the dossier still lacks a place image and stock failed again.
- Never call AI for abstract decoration when stock exists.
